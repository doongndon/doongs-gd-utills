# Daily Challenge

A roguelike run on a new level every day, the same for everyone, with a shared leaderboard.
Open it from the round clock button at the bottom of the main menu.

## Pick a difficulty

Each day has one level for every tab, and every tab is played as a roguelike run:

- **Main** - one of the main levels
- **Easy, Normal, Hard, Harder, Insane, Demon** - a random rated level of that difficulty
  (Demon means Easy Demon), drawn from the Geometry Dash servers

Every difficulty has its own cards and its own leaderboard. Attempts count from the first
time you open the level that day, practice runs included. Clears in practice mode or from a
start position do not count.

## The run

The game stops at 25%, 50% and 75% and offers three cards. Pick one and the run carries on
after a three-second countdown.

- **Help cards** cost points: Shield survives one death, Slow runs the game at 0.85x.
- **Curses** earn points: Mirror, Mini, Rush, Dark, Quake, Ghost, Silence, Blackout.

Dying loses every card - the next attempt starts empty. A clear scores 100 plus your cards;
the highest score wins and fewer attempts breaks ties. Everyone playing the same difficulty gets the same cards that day.

## Fair play

Results are taken on trust. The server cannot see how a level was beaten - this is a game,
not a tournament.
