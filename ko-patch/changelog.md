# v1.0.1
 - 처음부터 한국어로 쓰인 글(이 모드의 설명 같은)이 게임 글꼴에 한글이 없어 빈칸으로 보이던 것을 고쳤습니다. 이제 그런 글도 한국어 글꼴로 그립니다. 다른 한국어 글꼴을 쓰는 텍스처 팩이 있다면 "Use the bundled font" 설정을 끄면 됩니다.

# v1.0.0
 - 첫 공개판입니다.
 - Geometry Dash 2.2 의 문자열 4,872개, 업적 547개, 설정과 편집기 트리거 설명, 금고 대화, 로딩 화면 팁까지 한국어로 옮깁니다.
 - Geode 모드 관리자와 BetterEdit, Tinker, BetterInfo, NodeIDs 를 비롯한 여러 모드의 단추와 설정도 옮깁니다.
 - 게임 글자처럼 검은 테두리를 두른 한국어 글꼴(주아, 둥근모꼴 가운데 고름)로 그립니다.
 - 레벨 이름, 레벨 안에 만든 사람이 써 넣은 글, 모드 이름은 번역하지 않습니다.
 - 번역된 글자도 다른 모드에게는 원래 영어로 답하므로, 글자로 단추를 찾는 모드와 부딪치지 않습니다.
 - 업적 설명, 로딩 팁, 끝 화면 메시지, 상점 창의 글이 제자리에 놓이는 것을 기기에서 확인했습니다.
